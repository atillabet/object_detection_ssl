The Basic Loop

Semi-supervised object detection starts with a labeled detector, uses it to inspect unlabeled images, then retrains on the reliable new information. The whole method depends on filtering.

1. Train teacher Use your best labeled model as the first teacher.
2. Predict unlabeled Run SAHI/YOLO on unlabeled images and video frames.
3. Filter Keep stable real objects, reject or mine false positives.
4. Train student Train on real labels plus accepted pseudo data.
5. Validate Promote the student only if min-8 validation improves.

Why This Fits Your Case

Your model has background/context false positives and small-object noise. SSOD can help if it is used as a mining system.

Best first use: collect high-confidence false positives from unlabeled/video data and add those frames as negative training examples.

Do not auto-label everything: loose pseudo labels can teach the student to repeat the teacher's false positives.

Pseudo-positive

A model-generated box that probably marks a real object.

high confidence stable box >= 8 px

Hard negative

An image or crop where the model fires but there is no object.

Method Comparison

Select a goal to highlight methods that match your current problem.

Offline Pseudo-Labeling

easy

Train a teacher, predict unlabeled data, save high-confidence boxes, and retrain.

fast to implement needs strict threshold can copy FPs

Use when: teacher precision is already strong and unlabeled data is similar to validation data.

STAC-style Consistency

classic

Teacher makes pseudo labels on weak images. Student learns them under strong augmentation.

tests stability works with augmentations threshold sensitive

Use when: you want pseudo labels that survive blur, crop shift, color, or noise.

Unbiased Teacher

teacher-student

Uses an EMA teacher and class-bias handling so pseudo labels do not over-reinforce easy classes.

reduces bias more complex implementation work

Use when: your pseudo labels favor common/easy backgrounds or classes.

Soft Teacher

uncertainty

Uses soft weights and box jittering so uncertain pseudo boxes do not become hard truth.

good with noisy boxes better pseudo quality not trivial in YOLO

Use when: boxes are often close but not perfect, or confidence is poorly calibrated.

Hard-Negative Mining

your first step

Find false positives in unlabeled data and train them as empty-label images or corrected labels.

directly reduces FP YOLO friendly needs review

Use when: background textures, object-like fragments, or scene context trigger detections.

Temporal Consistency

video

Keep detections only if they persist across nearby frames with smooth motion and stable size.

filters random FPs uses tracking great for video

Use when: you have sequential frames and want to reject one-frame hallucinations.

Cross-Domain Teacher

domain shift

Adapts from labeled source data to unlabeled target data using teacher-student pseudo labels.

handles new cameras domain-aware heavier setup

Use when: performance differs strongly between validation sources.

Agreement Filtering

practical

Keep a pseudo label only if multiple models or multiple transforms agree on class and box.

simple high precision lower recall

Use when: false positives are costly and you can afford conservative pseudo-labeling.

Confirmation Bias

            
The teacher makes a false positive, pseudo-labeling saves it, and the student learns it harder.

            
Countermeasure: strict thresholds, stability checks, and a separate hard-negative bucket.

          

          

            
Domain Bias

            
If unlabeled data comes from one scene/camera, the student may improve there but regress elsewhere.

            
Countermeasure: track metrics separately for cars_ours, vis_drone_val, and video-like sources.

          

          

            
Missing Labels

            
A true object with no label can be mistaken for a false positive during review.

            
Countermeasure: every high-confidence FP should be inspected as "missing label vs real background".

          

        


        

          
Failure Symptoms And Fixes

          

            
              

                Symptom after SSOD training
                Likely cause
                Fix
              

            
            
              

                Recall improves but FP count explodes
                Pseudo-positive threshold too loose
                Raise threshold, require transform agreement, add hard negatives.
              

              

                Precision improves but recall collapses
                Too many hard negatives or too high threshold
                Reduce negative weight and add only stable pseudo positives.
              

              

                Only one validation set improves
                Unlabeled data is source-biased
                Balance unlabeled mining by source/domain.
              

              

                Object-masked score stays high
                Model still relies on background/context
                Add background randomization, hard negatives, and object-only consistency checks.
              

              

                Grad-CAM/D-RISE stays on tiny patches
                Pseudo labels reinforce small discriminative areas
                Use part dropout, blur/noise, tight crops, and shape-focused filters.
